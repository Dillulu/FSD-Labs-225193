Interactive Product Configurator — jQuery DOM Manipulation

Demonstrates jQuery selectors, event handling, real-time DOM updates, and dynamic class manipulation

📋 Task Overview

Build an interactive product configurator using jQuery. The configurator allows users to customize a Smart Thermal Tumbler by selecting a color finish, choosing the size/capacity, adding a laser engraving, and optionally unlocking premium features via a simulated purchase. All interactions are handled entirely through jQuery event handling and real-time DOM manipulation.

🎨

✍️

⭐

Simulated transaction with setTimeout. .slideUp()/.slideDown() animations reveal premium controls. .prop("disabled") management throughout.
💾
Save Configuration
Form submit handler (.on("submit")). Builds config object and appends a new card to the saved list using .append() with .fadeIn() animation.
🔤
Font Style Switcher
Three engraving font styles (Modern, Serif, Mono). Toggled via class names using jQuery .removeClass() + .addClass().

// jQuery selectors & event handling — Color Finish Selection
$(".color-swatch").on("click", function() {
    const $swatch = $(this);

});

Task 2 / Question 2

Public Product API Integration — jQuery AJAX GET Request

Demonstrates asynchronous AJAX requests, JSON response processing, dynamic rendering, and error handling

📋 Task Overview

Build a two-panel interface that sends a jQuery $.ajax() GET request to the public DummyJSON REST API (https://dummyjson.com/products). The retrieved product data is dynamically rendered as product cards using $.each() and jQuery DOM manipulation. A product can be selected to populate the integrated configurator on the right panel. The interface also features full error handling, live API endpoint display, and a raw JSON inspector.

🔗 How AJAX Works in This Task

When the user clicks "Fetch Public Products", jQuery dispatches an asynchronous HTTP GET request to the DummyJSON API. While waiting, the status bar shows a pulsing "loading" indicator. On success (HTTP 200), $.each() iterates through the products array and appends a card per item. On failure, the error callback displays the HTTP error code and disables the render area.

💻 Core AJAX GET Request Code

// jQuery $.ajax() GET request to public DummyJSON API
$.ajax({
    url: `https://dummyjson.com/products?limit=${limit}`,
    method: "GET",
    dataType: "json",
    timeout: 10000,
    success: function(response) {
        console.log("%c[AJAX 200 OK]", "color:#16a34a;", response);
        fetchedProducts = response.products;
        renderCatalog(fetchedProducts);   // Build product cards
        setStatus("success", "Loaded " + response.products.length + " products.");
    },
    error: function(xhr, status, error) {
        console.error("%c[AJAX Error]", "color:#dc2626;", { status: xhr.status, error });
        setStatus("error", "HTTP " + xhr.status + ": " + xhr.statusText);
    }
});
// Dynamic catalog rendering using jQuery $.each()
function renderCatalog(products) {
    const $container = $("#catalog-products-container").empty();
    $.each(products, function(index, product) {
        $container.append(`
            <div class="catalog-item-card">
                <img src="${product.thumbnail}" alt="${product.title}">
                <h4>${product.title}</h4>
                <span class="card-price">$${product.price}</span>
                <button class="btn-select-prod" data-id="${product.id}">Configure &rarr;</button>
            </div>
        `);
    });
}

Task 3 / Question 3

Student Management System — Express.js REST API + jQuery POST

Full-stack: Express.js backend with GET & POST endpoints, CORS middleware, jQuery AJAX frontend

📋 Task Overview

Build a complete full-stack application. The backend is an Express.js REST API server running on localhost:3005. It exposes two endpoints: GET /api/students returns all student records as JSON, and POST /api/students receives a new student object, validates required fields, appends it to the in-memory store, and responds with HTTP 201 Created. CORS middleware (cors npm package) is applied so the separate jQuery frontend can communicate cross-origin without browser security errors.

Figure 3.1 — Task 3: Student Management System Frontend with Express server online (green dot), GET table panel & POST form panel

💻 Express Backend Server Code

const express = require("express");
const cors    = require("cors");
const app     = express();

// In-memory student data store
let students = [
    { id: 1, name: "Hamza Tahir", regId: "225193", city: "Islamabad", age: 20, grade: "A" },
    { id: 2, name: "Ali Hassan",   regId: "225101", city: "Lahore",     age: 21, grade: "B" }
];

app.use(cors());           // Enable CORS for all origins
app.use(express.json());  // Parse JSON request bodies

// GET /api/students — Return all records
app.get("/api/students", function(req, res) {
    res.status(200).json({ success: true, count: students.length, students: students });
});

// POST /api/students — Add new student
app.post("/api/students", function(req, res) {
    const body = req.body;
    if (!body.name || !body.city || body.age === undefined) {
        return res.status(400).json({ success: false, message: "name, city and age required" });
    }
    const newId = Math.max(...students.map(s => s.id)) + 1;
    const newStudent = { ...body, id: newId, age: Number(body.age) };
    students.push(newStudent);
    res.status(201).json({ success: true, message: "Student added.", student: newStudent });
});

app.listen(3005, () => console.log("Running at http://localhost:3005"));

                $("#students-tbody").append(`<tr><td>${s.id}</td><td>${s.name}</td>...</tr>`);
            });
        }
    });
});

// AJAX POST request — Submit new student form
$("#add-student-form").on("submit", function(e) {
    e.preventDefault();
    const payload = { name: $("#f-name").val(), city: $("#f-city").val(), age: $("#f-age").val() };

        contentType: "application/json",
        data: JSON.stringify(payload),
        success: function(data) {
            console.log("201 Created:", data.student);
            // Append new row to table, show JSON response
        }
    });
});
